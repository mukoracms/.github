# Support

Thanks for using a Simtabi open source project. Here is how to get help, fastest
first:

1. **Issues** — for bugs and feature requests, open an issue on the relevant
   repository, if you have access to it.
2. **Email** — [opensource@simtabi.com](mailto:opensource@simtabi.com) for
   anything else, including access questions.

Mukora repositories are private while the interfaces settle, so most support runs
through your usual contact rather than a public tracker.

Security vulnerabilities are the exception: never report those publicly. See
[SECURITY.md](SECURITY.md).
