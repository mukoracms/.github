# mukoracms/.github

> Organization-wide community health files and the org profile for the
> [mukoracms](https://github.com/mukoracms) organization.

`profile/README.md` renders at [github.com/mukoracms](https://github.com/mukoracms).
The default `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, and
`CODE_OF_CONDUCT.md` here apply to every mukoracms repository lacking its own.

Mukora repositories are private at time of writing. The health-file cascade still
applies to them, and this repo is public so the org profile can render.
